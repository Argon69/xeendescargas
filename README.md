# 🎯 XEEN STORE - Repositorio de Descargas
### By NIXON

Un repositorio moderno de aplicaciones y recursos para Windows y Android, con diseño minimalista blanco y funcionalidad PWA instalable.

## ✨ Características

### 🎨 Diseño Minimalista Blanco
- **Fondo blanco limpio** con diseño profesional
- **Cards modernas** con gradientes coloridos y sombras sutiles
- **Iconos grandes** en lugar de imágenes placeholder
- **Badges elegantes** (POPULAR, NUEVO, TOP)
- **Responsive Design** optimizado para móviles, tablets y desktop
- **Logo único XN** - Simple y memorable

### 🚀 Funcionalidades

#### Navegación
- **Sidebar deslizante** desde la derecha (mismo lado del botón)
- **Toggle button** - abre y cierra con el mismo botón
- **Cierre con ESC** - navegación por teclado
- **Smooth scroll** en enlaces anchor
- **Overlay con blur** al abrir el menú

#### Sistema de Favoritos
- **Contador dinámico** con badge animado
- **Toast notifications** al agregar/quitar favoritos
- **Persistencia visual** con iconos que cambian de estado
- **Modal informativo** cuando no hay favoritos

#### Búsqueda
- **Búsqueda en tiempo real** en desktop y móvil
- **Mensaje "sin resultados"** cuando no hay coincidencias
- **Animaciones** en los resultados filtrados

#### Descargas
- **Alertas personalizadas** con SweetAlert2
- **Links directos** a Google Drive, GitHub y MediaFire
- **Indicadores visuales** de descarga en progreso

#### 📱 PWA (Progressive Web App)
- **Instalable** como aplicación nativa
- **Service Worker** para funcionalidad offline
- **Manifest.json** configurado
- **Icono personalizado** en la pestaña del navegador
- **Funciona offline** con caché inteligente

#### 🔒 Privacidad y Seguridad
- **NO recopilamos datos** personales
- **NO almacenamos** información del usuario
- **NO usamos cookies** de seguimiento
- **Páginas legales** completas (Términos y Privacidad)
- **Datos locales** solo en tu navegador (favoritos)

## 🚀 Instalar como PWA

1. Abre el sitio en Chrome/Edge/Safari
2. Busca el ícono de "Instalar" en la barra de direcciones
3. Click en "Instalar XEEN STORE"
4. La app aparecerá en tu menú de aplicaciones

### En Móvil (Android/iOS):
1. Abre en navegador
2. Menú (⋮) → "Agregar a pantalla de inicio"
3. Confirma la instalación

## 📱 Responsive Breakpoints

- **Mobile**: < 640px (1 columna)
- **Tablet**: 640px - 1024px (2 columnas)
- **Desktop**: 1024px - 1280px (3 columnas)
- **Large Desktop**: > 1280px (4 columnas)
